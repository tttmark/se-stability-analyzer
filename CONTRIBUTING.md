# Contributing

Contributions are welcome.

1. Fork the repository and create a feature branch.
2. Keep the core package dependency-free unless a dependency provides clear value.
3. Add or update tests for behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request describing the change and its scientific assumptions.

For metric changes, document the formula and avoid presenting heuristic scores as
standardized scientific measures.
